## Why this license

Apache-2.0 is a permissive open-source license suited to public research,
Buildathon review, and enterprise reuse. It includes an express contributor
patent grant while allowing redistribution and modification subject to its
terms and notice requirements.

## Release checks

1. Keep top-level `LICENSE` present and unmodified.
2. Keep project metadata aligned to `Apache-2.0`.
3. Preserve any third-party attribution or separate asset terms if introduced.
4. Add a `NOTICE` file only if required attribution notices are introduced.
5. Do not describe the project as production-ready merely because it is
   open-source; payment, security, and checkpoint evidence claims remain
